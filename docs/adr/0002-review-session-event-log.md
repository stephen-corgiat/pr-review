# A Review Session is an append-only event log

A Review Session is stored as an append-only JSONL log of the engine's events (a Question asked, an Answer arrived, a Probe allowed, Feedback drafted, revised or posted, the head moved), not as a snapshot or a database. These are the same events the engine emits to the UI through its message API, so what we store is exactly what the UI receives. The current state is rebuilt by replaying the log, which is also how resume works, and the log can be mined later just by reading the file. The log records the agent's session IDs, so a Thread can pick up its agent session again. It lives in the user's data directory (`~/.local/share/…` on Linux, `~/Library/Application Support/…` on macOS), one directory per repo and Pull Request, never inside the repo under review.
